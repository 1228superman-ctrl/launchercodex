# Contributing / 贡献指南

Thank you for helping improve **Codex 动漫启动器 | Codex Anime Launcher**.

1. Open an issue describing an actual bug, reproducible media problem, Windows launcher behavior, or documentation gap.
2. Keep changes focused. Use the same Python standard library + FFmpeg approach unless a new dependency has clear benefits.
3. Run `python -m unittest discover -s tests -v` before opening a pull request.
4. Never commit recorded private chats, user files, commercial anime footage/music, passwords, API keys, or authentication tokens.
5. Call out Windows-only behavior; do not claim wallpaper customization or end-to-end launch works without real tests.
6. Prefer new non-destructive outputs, read-only inspections, safe dry-runs, backups and straightforward rollback.

中文版：欢迎修复问题、完善教程和测试；提交前必须运行测试，禁止提交个人聊天、商业版权素材及密钥。对于尚未实测的安装和恢复功能请如实标注限制。
