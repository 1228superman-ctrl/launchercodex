# v2.0.0-beta.1 — Codex 动漫启动器 | Codex Anime Launcher

**First public beta candidate / 首个公开测试版本**

- Reusable bilingual Agent Skill and text-only Gojo V13 audio-editing example.
- FFmpeg-based existing-video assembly with horizontal/vertical export and matching frame rate.
- Standard-library procedural keyboard, wheel and click sounds; music mixing supports silent scrolling/icon scenes and gradual character-reveal crescendo.
- Audio/video verification, picture-bitstream SHA-256 comparison, reproducible automated tests.
- Optional Windows shortcut wrapper, separate original backup and restore documentation.

**Not included:** Gojo artwork/video, any commercial song such as SPECIALZ, private recordings, a text-to-video model, an official Codex wallpaper patch or a bundled mpv/FFmpeg binary.

**Beta limitations:** Windows shortcut install/launch/fallback/restore still needs real-device testing; supported native Codex chat backgrounds depend on app version and are **not** implemented by this package.

This project is unofficial and is not affiliated with or endorsed by OpenAI.
