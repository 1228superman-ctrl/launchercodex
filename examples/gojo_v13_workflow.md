# 已完成项目复盘：五条悟 / Codex V13 声画设计实例

此文记录经用户多轮对比后的**可重用制作逻辑**，不是随 Skill 分发第三方动漫音乐或角色视频。完整成片保留在原作者自己的项目盘；包内仅保留时轴配置与做法。不同用户须替换合法素材，并重新设置时间点。

## 1. 原视频镜头节点（真实项目）

| 时刻 | 视频内容 | V13 处理 |
|---|---|---|
| 0.00–2.39 | 真实聊天指令输入 | 连续、略有节奏起伏的键盘音效 |
| 2.39–7.625 | ChatGPT 回复、聊天历史滚动 | **不放背景音乐**；鼠标滚轮声仅在实际滚动时出现（原项目主要在约 4.40–7.49 秒） |
| 7.625–10.625 | Codex 图标出现、点击，蓝色能量转场 | **不放背景音乐**；保留音量很轻的 UI / 点击声 |
| 10.625–19.375 | 五条悟画面逐渐显现 | 《SPECIALZ》用户提供片段从原曲 55 秒起播放，低音量进入并逐渐增强 |
| 19.375–22.208 | 人物转成 Codex 主题 UI | 逐步淡出至无声 |

曲目只说明原用户选择与剪辑锚点。《SPECIALZ》归相关权利人所有，音乐文件**不随 Skill 分发**，公开传播前核实使用授权。重新使用时选已授权曲目，并在配置 `music.song_offset_seconds` 填自己的音乐起点。

## 2. V13 的关键逻辑

- 叙事规律：**真实操作 → 安静转场 → 角色出场音乐渐强 → 收束**。前半段不要整段铺音乐，以免把后半段的情绪反差提前用完。
- 渐强不是把整段歌曲一次性设置成固定高音量，而是「0.09 的低音量底层 + 在约 7.35 秒内渐入 0.65 的主体」；界面出现后在约 2.83 秒中淡出。
- 旧版 V10-V12 以及原创音乐 A/B 对比版保留。每次返工只替换音轨，不改变已验收的画面。
- 音效阶段单独验收：鼠标滚轮声可听但不刺耳；图标阶段绝无歌曲；角色显现前段、中段、后段的响度逐渐上升。

## 3. 事实边界

这套声画做法曾在用户的 Windows 工作环境中实际用 FFmpeg 生成竖版 / 横版并进行解码、响度与画面比对；但这些 Windows 项目路径和媒体文件**不在本 Skill 包中**。

视频结尾可能包含以历史真实 Codex 截图重新合成的「侧栏收起」演示效果，**不是证明新版 Codex 客户端当前仍支持该图片背景**。启动器真实接入必须另行安装和测试。

## 4. 换成其他角色

换主题不改声音逻辑，只更新 `templates/storyboard_template.md` 中的角色、色彩、实际转场节点、曲目授权说明；再将 `examples/gojo_v13_audio_timeline.json` 的时间改为**新的视频实测事件时间**。

**不要按 22 秒样例直接比例拉伸全部时刻**：重新观看实际打字、滚动、图标和角色显现的帧，再设定 `video_duration`、每段开始结束和音乐起止。
