# Codex 背景与主题：不要混淆原生配色、图片壁纸和演示镜头

## 分层理解

**第 1 层（优先）**：Codex Desktop → Settings → Appearance。按用户的真实版本操作，支持的控制通常包括主题、accent、background/foreground colors、字体。这是界面的真实设置，更易更新与回退。颜色背景并不等于图片壁纸。

**第 2 层（需要版本级验证）**：若当前版本真的有受支持的自定义图片背景/壁纸入口，则按官方入口导入图片。不能仅靠“主题展示视频”的截图判断它存在。

**第 3 层（独立审批）**：第三方外观插件、窗口叠层、注入 CSS/JS、改安装资源、app.asar 等，在兼容、隐私、更新与完整性方面风险不同。默认不做；尤其禁止直接更改安装包与用户登录数据。用户明确要求图片底图但原生不支持时，坦白说明替代方案或暂不实现，不能伪造已生效的壁纸。

## 五条悟配色示例（不强制）

- 基础：暗色（Dark）
- 背景：深蓝黑 `#0A111F`
- 前景：近白 `#E9F3FF`
- 强调：冰蓝 `#67CAFF`
- 人物壁纸布局：主角在左侧非交互区；聊天/代码区域保持低细节与高可读性；避免文字可读性被高亮能量破坏。

提示：这些色值只是视觉建议，最终必须按实际应用界面的字段与显示效果调整。

## 验收证据

- 打开正在运行的 Codex，切换至实际的聊天/项目页面并检查；不能只看 `intro.mp4`。
- 记录 Codex 版本与采用的设置入口；保留默认主题恢复说明。
- 将“完成原生配色”与“已实现图片背景”分列，不互相替代。

## 社区方案调查（2026-10，非默认自动安装）

- Windows 的 `TonyNa-code/codex-background-theme`（GitHub：`https://github.com/TonyNa-code/codex-background-theme`）声称可给 Codex 添加图片壁纸、玻璃 UI；其 README 明确说明 **Windows 仍属实验性**，通过修改本地 Codex 资源/ASAR 工作，存在安装、更新与完整性风险。仅做可选研究对象，不能自动安装或作为零风险替代。
- `cixiangtao/codex-skin`、`irons163/codex-theme-switcher` 主要适用 macOS，不能直接拿来当 Windows 方案。
- Windows Codex 如遇侧边栏异常透出桌面、最大化不正常，可以先尝试 `Settings → Appearance` 关闭半透明侧栏，再检查效果。这属于独立的显示问题排查，不等于完成美术主题。
