# 交付前验收清单

## 媒体（脚本 + 人工检查）

- [ ] 原素材路径和导出路径不同，所有旧版本仍存在。
- [ ] 解码完整无错误；MP4 有 video/audio 轨；时长、帧率、横竖分辨率符合计划。
- [ ] 比较静音画面流与配乐成片的视频流哈希一致，未改变画面。
- [ ] 与实际输入时刻同步的键盘声，播放时不出现错位。
- [ ] 聊天记录滚动时只有滚轮声、没有歌曲（静止帧不应有不必要的滚动声）。
- [ ] Codex 图标转场有轻微点击声，但没有音乐。
- [ ] 角色开始出现才开始音乐；逐渐增强；角色完全出现或转入 UI 时进入最高/收尾阶段；结尾淡出。
- [ ] 手动听完整成片，耳机与外放均无明显爆音、破音或首尾咔哒。
- [ ] 画面不存在隐私、展开侧栏、异常马赛克、不规则形状或突兀重叠。
- [ ] 如存在“真实软件界面”描述，有真实客户端实机证据，而非后期合成截图。

命令示例：

```bash
python scripts/verify_output.py --video exports/intro.mp4 --compare-video-to work/video_silent.mp4 --timeline templates/audio_timeline.json --report exports/qa.json
```

## Windows 接入（只在获授权后）

- [ ] 默认只新建快捷方式，原始 `.lnk` 备份已存在。
- [ ] 原始 Codex 快捷方式可独立启动；MPV 播放器确实可用。
- [ ] 播放启动动画完毕后成功打开真实 Codex，历史聊天/工作区正常。
- [ ] 跳过或缺少播放器时，仍能启动原 Codex。
- [ ] 自定义图标在需要的快捷方式上生效；任务栏另行验证。
- [ ] 恢复方案实际验证，且无需触碰安装包。
